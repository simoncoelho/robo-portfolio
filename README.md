# robo-portfolio

This is the README for my robot portfolio site.

I built this as a small interactive portfolio around lab automation, robotics, and scientific software. The site uses React and Three.js to render a robot workcell-style scene where portfolio sections are represented as lab plates on a shelf.

My work is focused on software at the intersection of biotech and automation: instrument integrations, workflow orchestration, AI-assisted lab systems, and tools that make scientific work more repeatable.

## Run It

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
